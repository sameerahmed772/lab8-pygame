Study Summary

Four themes dominate the codebase: typed runtime data, a loop-driven Pygame simulation, event-controlled state changes, and pytest-based checks around square creation, movement, and input handling.

State Modeling

`Square` and `GameState` keep runtime data explicit, which makes the update loop easier to reason about and test.

Simulation Loop

`main()` wires initialization, event handling, updates, rendering, and frame pacing into one continuous cycle.

Movement Rules

`update_squares()` combines lifespan expiry, flee/chase steering, friction, speed caps, wall bounce, and collisions.

Interaction and Tests

`handle_events()` maps keys and mouse clicks to state changes, while `test_main.py` isolates those branches with mocks.
